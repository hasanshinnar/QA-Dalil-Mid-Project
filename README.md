# QA-Dalil-Mid-Project : EduShop E-Commerce Platform — QA Testing

A comprehensive Quality Assurance (QA) testing portfolio for **EduShop**, a training e-commerce platform. This repository showcases end-to-end **Manual Testing** (Functional & UI) and **API Testing** (Contract, Validation, and Authorization) executed using industry-standard tools like **Jira, Zephyr, and Postman**.

---

## Project Overview

**EduShop** consists of an Angular frontend, an ASP.NET Core 8 Web API backend, and a PostgreSQL database. It supports two main user roles: **Customer** and **Admin**.

This portfolio demonstrates structured test planning, test case design, execution tracing, and defect lifecycle management.

### **Tech Stack & Testing Tools**

- **Test Management:** Jira, Zephyr Scale/Squad
- **API Testing & Documentation:** Postman, Swagger UI
- **Database & Environment Management:** PostgreSQL, pgAdmin, Docker
- **System Under Test (SUT):** Angular (Frontend), ASP.NET Core 8 (Backend API)
